# Murari Bucket Biryani

Single-page website for **Murari Bucket Biryani, Tenali** — menu, prices and direct WhatsApp ordering.

## Structure

- `index.html` — the complete site (HTML, CSS and JS in one file)

## Hosting (GitHub Pages)

1. Repo **Settings → Pages**
2. **Source:** Deploy from a branch → **main** → **/ (root)** → Save
3. Site goes live at `https://mnpapps.github.io/muraribucketbiryani-/`
